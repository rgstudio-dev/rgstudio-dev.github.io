개인정보처리방침

앱: 사주가 로또를 만났을 때
시행일: 2026년 11월 24일

레트로 게임즈 스튜디오(이하 "회사")는 「개인정보 보호법」 등 관련 법령을 준수하며, 「사주가 로또를 만났을 때」 앱에서 처리하는 개인정보를 투명하게 안내하기 위해 이 개인정보처리방침을 제공합니다.

1. 수집하는 개인정보 항목

앱은 다음 정보를 사용자 기기의 로컬 저장소에 저장합니다.

  • 생년월일
  • 태어난 시간 또는 "시간 모름" 선택 여부
  • 성별
  • 생성된 로또 번호 세트와 생성 일시
  • 사주 분석 결과 및 기기 내 앱 설정 정보
  • 추천 번호에 대한 회차별 이력과 추첨 결과 확인 상태

앱은 위 정보를 회사의 서버로 전송하거나 회사가 별도로 보관하지 않습니다. 단, 앱이 최신 추첨 정보를 확인하기 위해 동행복권 공식 웹사이트에 접속할 때 이용자의 IP 주소, 브라우저 또는 앱 환경에 관한 일반적인 네트워크 정보가 해당 웹사이트에 제공될 수 있습니다.

2. 개인정보 이용 목적

  • 생년월일, 태어난 시간, 성별을 이용한 사주 분석
  • 사주 분석 결과에 따른 로또 번호 생성 및 표시
  • 생성한 번호와 추첨 이력의 기기 내 보관
  • 동행복권 공식 추첨 정보의 확인 및 지난 추천 번호와 당첨 번호의 비교
  • 소리 설정 등 앱 기능 제공 및 이용 환경 유지

앱은 사주 분석과 로또 번호 추천을 위한 목적으로만 데이터를 사용합니다. 당첨을 보장하지 않으며 모든 번호는 참고용으로 제공됩니다.

3. 개인정보의 저장 위치와 보존 기간

생년월일, 태어난 시간, 성별, 추천 번호 이력과 앱 설정은 사용자의 기기에만 저장됩니다. 저장 정보는 사용자가 앱을 삭제하거나 기기 앱 설정에서 앱의 저장 공간을 지우거나 앱의 저장 데이터를 삭제할 때까지 보관됩니다.

앱은 서버에 개인정보를 보관하지 않으므로 회사가 별도로 이용자의 데이터 삭제 요청을 처리하는 서버 데이터는 존재하지 않습니다.

4. 개인정보의 제3자 제공 및 외부 전송

회사는 앱에서 입력한 개인정보를 광고주, 분석 업체 또는 기타 제3자에게 판매하거나 제공하지 않습니다.

앱은 최신 추첨 결과를 확인하기 위해 동행복권 공식 웹사이트에 접속합니다. 이 과정에서 발생하는 네트워크 접속과 해당 웹사이트의 개인정보 처리에 관한 사항은 동행복권의 개인정보처리방침이 적용될 수 있습니다. 동행복권 공식 웹사이트는 별도의 운영 주체가 관리하는 외부 서비스입니다.

현재 앱 버전에는 광고 SDK, 계정 로그인, 사용자 행동 분석 SDK 또는 푸시 알림을 위한 개인정보 수집 도구가 포함되어 있지 않습니다. 다만 추후 해당 기능이 추가되면 이 방침을 업데이트하고 앱 내 안내를 제공합니다.

5. 로컬 저장소와 권한

앱은 사주 정보와 추천 번호 이력을 저장하기 위해 기기의 로컬 저장소를 사용합니다. 현재 앱은 생년월일과 성별을 직접 저장하기 위해 별도의 서버 계정을 만들거나 위치, 연락처, 사진, 카메라, 마이크 또는 기기 고유 식별자를 사용할 권한을 요청하지 않습니다.

앱의 배경음악과 효과음 재생을 위해 필요한 기능 외의 기기 권한은 요청하지 않습니다.

6. 이용자의 선택과 삭제 권리

이용자는 언제든지 앱 내 사주 정보를 수정할 수 있습니다. 저장된 사주 정보와 추천 번호 이력을 삭제하려면 앱을 삭제하거나 Android의 "설정 > 앱 > 사주가 로또를 만났을 때 > 저장공간 > 데이터 지우기"를 선택할 수 있습니다.

7. 아동의 개인정보 보호

본 앱은 성인이 사주와 로또 번호를 참고 용도로 이용하는 것을 기본 사용 대상으로 합니다. 회사는 아동을 대상으로 개인정보를 의도적으로 수집하지 않습니다. 보호자의 동의 없이 아동이 개인정보를 입력한 경우 보호자는 아래 문의처로 연락하여 삭제 방법을 문의할 수 있습니다.
